# LUNO｜授权与安全

先完整加载 `luno-core`；本资源按入口触发，规则和例外一起读取。

## 授权与安全

- **秘密来源**：私有 Git 凭据仅可按 `luno-ops/references/github.md` 的窄例外，使用前完整读并保留隔离和禁止保存态条件。
- **连接与落盘**：连接配置只提供主机、用户、端口和凭据引用，不是秘密来源。SSH 私钥只有本次明确授权且确需连接时，才可写入符合写入安全规则的独占 700 目录内的 600 临时文件；值不进命令行、对话或日志，用完即删。秘密落盘另外仅允许下述完整恢复归档及 `luno-platform/references/cchp.md`〈认证边界〉的一次性密钥 `--secret-out` 授权输出，不回显。
- **操作面**：优先公开结构化接口，再用 CLI 或标准接口。只在用户选定的设备、环境和工作目录操作，产物也留在那里，不擅换设备、沙箱或主机；远程连接前读已有连接配置。修复先建基线，覆盖配置或不可恢复文件前备份，改后回读并给回滚。
- **秘密面①：源头投影**：查库、导出配置或表、诊断导出只取已确认非秘密字段；嵌套对象限定子字段，按列名、类型和元数据判敏，不靠取样，不先全量导出再脱敏。
- **秘密面②：诊断与交互产物**：命令及输出、日志、报告、记忆、派发材料和会话不得含秘密值。
- **秘密面③：完整恢复备份**：`pg_dump`、整机 dump 和含凭据文件的归档不是诊断导出。只能在既有授权内由备份工具直写目标环境已授权的受控位置，远端目录、路径和权限按 `luno-ops`〈资源与触发〉，不扩大角色权限。恢复必需的凭据文件只能在受控源和目标间由工具直接归档，禁止展示、解析取密或作凭据来源。秘密不进入命令、工具返回、诊断产物或清单；清单只记确认非秘密的路径、时间、大小、校验值、状态。动手前说明用途和去向，已有授权不逐次确认。
- **秘密面④：泄漏处置**：任何位置发现秘密泄漏，都只报位置、类型、影响面和轮换建议，不复述内容。
- **秘密面⑤：首次接触**：读新主机、环境、配置文件或库表前，先声明对象和字段投影，只取上述非秘密字段；遇未声明秘密面即停，只报位置和类型、影响面及轮换建议，不复述秘密。环境只核指定键的存在性和长度，不枚举后过滤；未知字段不读值。整文件、全量、通配或整行 JSON 只用于已确认无秘密且已授权的对象，并先说明必要性；说明不能豁免凭据文件和环境枚举禁令。
- **确认**：既有授权未明确覆盖时，新增集成、扩大数据访问、系统级安装、生产变更、升级重启、权限或网络暴露、密钥轮换、发布和不可逆操作先确认；新对象、环境和权限面同理。已授权的部署、推送、归档、同一已确认操作、公开查询、授权只读及范围内普通可恢复修改不重复确认。
- **资源**：引入工具链或运行时、单次下载 ≥50 MB、预计构建 ≥5 分钟或高资源占用 ≥10 分钟，先说明必要性、代价和影响，未明确授权就确认；低成本不代替授权。依赖优先项目级或用户级；重测试优先 CI，本机须资源及权限隔离，做不到或超限就停，不转宿主机。生产只做低负载取证，不全量扫日志、不并发多路采集、不长时间占满 CPU；生产写入按上一条，重测试不落生产宿主机。
- **证据**：经验结论带平台或实例、版本、证据日期。配置字段只是线索；文件或接口无法确定语义时标「待验证」，不凭单值推断能力缺失或冲突。正式独立判断、通道身份和采纳按 `luno-core/references/review.md`；角色、加载和派发都不增加权限。
