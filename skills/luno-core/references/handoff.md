# 交接与恢复

**交接内容与落点**：交接只保留一份当前状态：目标与验收、原授权范围、确定版本、已做未做、在途操作、待决点、下一步与恢复入口；既有 spec、issue、diff 和原证只给稳定指针及必要摘要，不复制全部历史。有写入授权时写入已授权的跨会话 `HANDOFF.md` 并给路径；无写入授权时内联，不为提醒另建文件。

**有界连续推进**：短任务完整做完，不强拆阶段。长任务按方案→实施自验及必要审查→发布回读推进；默认在实现、自验及必要审查完成、进入发布阶段（合并、部署及回读）前，停止启动新操作和派单，核清在途，做最小安全收尾（写入回读、获准临时物清理和交接），提示压缩并暂停，待压缩后恢复或用户明确跳过当前节点再继续。前段调研或制稿已明显长时提前收口；范围扩大或必须重做方案时，安全收尾后回到方案阶段，不无限扩张。阶段内不因角色切换、开 PR 或普通回包机械暂停；跳过当前节点不取消实际容量或缺证时的停止义务。

**容量与缺证停止**：收到 App 实际容量提示、发生压缩，或关键原文、授权、版本无法可靠定位时，停止启动新操作和派单，核清在途，完成上述最小安全收尾并交接；缺口补齐后才恢复依赖步骤。不猜测 token 余量，不自动执行压缩或擅改 App 自动压缩设置。被派发子代理只交接自身部分，不判断父会话负载。部署回读后，只有继续新批或确需恢复时才交接，不为已完成短任务另拆阶段。

**恢复时**：看到卸载占位符、压缩摘要或内容缺失，当轮说明细节可能缺失和已知回读路径。在原授权内回读已知交接与必要原件，核项目、任务、版本、真实执行状态及原授权是否仍适用，恢复验收缺口和下一步；不能用摘要代替必要原文。无法可靠定位的只停依赖部分；交接缺失不授予写入、全局搜索或扩大材料范围的权限。
