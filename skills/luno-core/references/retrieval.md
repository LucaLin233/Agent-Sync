# 联网检索

向第三方搜索或抓取服务提交查询、URL或正文前，先核既有外发范围与授权；查询、URL和正文不得夹带秘密值。非公开个人信息、非公开内部信息、非公开URL及登录态内容，仅在既有明确授权覆盖向相应服务外发这些数据时处理；无授权仅停对应外发，不扩大为全面禁搜。公开材料（含任务所需的公开个人信息）在既有检索授权内直接处理，不逐次确认；上述授权不替代密钥引用授权，不放宽秘密来源和输出限制。末级公开代理仍须遵守下文更严格限制。

按入口〈路由〉先搜，不以本地无记录为条件；官方文档与上游 issue 优先。同一现象试错两轮无进展即检索或换有依据路径，不反复试探；不为省额度跳过必要检索。参数明确即调用、不重复确认；以够判定为准，不设条数/次数上限。默认 Exa；精确文本、长尾、站点/日期筛选用 Keenable；不足再换源，已知 URL 直接读。关键结论鼓励两者交叉核对。非时效正文先 Exa，可批量；空文、错误/拦截页、目录占位、缺所需段落时换 Keenable 一次，不单凭长度重抓；最新原文用已支持的实时抓取。每个关键结论至少一个可核验原文来源（URL、日期、版本）；外部事实附来源，取不到标未核实、不作定论前提，不推测补证、不凑证据。限长保留关键证据；搜索与正文提取优先使用当端可用的 Exa/Keenable MCP；调用前核工具定义及授权，工具名、参数、认证与请求实现以实际工具定义为准，不预设端侧能力。所需 MCP 不可用时如实报告；仍可在既有授权内使用当端可用的原生/浏览器搜索或直接读取已知公开 URL，不自动改走 REST。不套另一端 CLI、不猜参数；入口可见或配置存在不证明连通或调用成功。

结果仅候选，非验证；深研标已答/冲突/未答，按缺口推进，无助判定即停。
发布日期、索引时间、缓存年龄与历史快照须区分；历史内容非历史排序，限定历史索引不等于取得历史原文。按实际工具支持核对时间筛选与新鲜度语义；成功返回仍逐 URL 核验正文，定向提取或摘要不代原文验证。
仅在工具实际暴露 HTTP 状态码时按码处理：400 按错误体修参；401 停止并报告认证问题、禁转匿名；402 报额度问题；403 按错误体区分本方权限／策略与源站拒绝，不误报认证故障、不盲重试；429 按 Retry-After 或指数退避有界重试，耗尽即报。未暴露状态码不猜测；前置代理／访问层错误不得冒充服务端错误。
