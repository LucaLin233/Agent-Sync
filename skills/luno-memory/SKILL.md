# LUNO｜经验与记忆纠错

- 本端记忆写入/检索/更正前，完整读取 `references/maintenance.md` 并选本端入口；不绕过关闭、工具或权限限制。用户纠正、自验错误、事故、复发或固化候选，即使不写记忆也基于已授权材料分诊：事实/偏好纠正给更正及依据；事故、复发或疑似规则缺口按该资源处理并交处置。未知不定因，不为填字段新增记忆。记忆各端自持，LobeHub 知识库不作跨端载体、不回写 Minis。

## 检索与采用

- 先取一个辨识度高的关键词；结果过多再加第二个限定词，无结果先减少限定词、再试已知别名、旧称或上位词。**多词须同时命中、排序含时间权重、首条不保证最新或仍有效**属 Minis 既有观测（版本未记录），不推广到其他端，也不承诺现版本行为。
- Minis 首次记忆操作前完整读取 `references/maintenance.md`，依〈Minis 记忆读写入口〉选定入口；检索不可用时只在授权内按已知文件日期与主题定位，不声称已检索或查重。
- 采用前核对命中条目的平台/实例、版本、证据日期与状态（已订正／已替代／已撤销／待验证），与当前环境、版本和命题范围对齐后再引用；不把单端实测、历史观测或背景摘要当作现行结论——现行规则以常驻提示词与技能为准，条目只作背景。

## 资源与触发

写入/整理/更正记忆、用户纠正、事故或错误复发及相关规划审查前，必须完整读取 `references/maintenance.md`；涉及 Minis 记忆日志注入、截断或容量评估及相关建议或结论时，同样先读取该资源，再由其按需转到 `luno-minis` 的注入资源；加载不新增授权。

## 诚实边界

- 只报“已从指定文件删除并回读确认”，不声称清除历史会话、备份、Git 历史、压缩摘要或当前上下文副本。
