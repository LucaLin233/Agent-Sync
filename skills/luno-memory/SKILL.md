# LUNO｜经验与记忆纠错

记忆各端自持：LobeHub 知识库不作跨端载体，也不回写 Minis。普通的事实或偏好纠正，以及已经定位的单次自验错误，直接给出更正、依据和适用范围，不因纠正本身加载维护资源；只有涉及记忆更正、事故或复发、固化候选或疑似规则缺口时，才基于已授权的材料按维护资源分诊和处置。原因不明就不下定论，也不为凑字段新增记忆。

## 资源与触发

实际读写、整理或更正记忆，处理事故或错误复发、固化候选、疑似规则缺口，以及对它们做规划或审查之前，完整读取 `references/maintenance.md`。涉及 Minis 记忆日志的注入、截断或容量评估及相关建议或结论时也先读它，再由它转到 `luno-platform/references/minis.md` 的注入资源。Minis 上第一次做记忆操作前，按其〈Minis 记忆读写入口〉选定入口。

## 检索与采用

- **检索**：先用一个辨识度高的关键词；结果太多再加一个限定词；没有结果时先减少限定词，再试已知的别名、旧称或上位词。「多个词须同时命中、排序含时间权重、首条不保证最新或仍有效」是 Minis 上的既有观测（版本未记录），不推广到其他端，也不保证现版本仍然如此。检索不可用时，只在授权内按已知的文件日期和主题定位，不声称已经检索或查重。
- **采用**：引用命中的条目前，核对它的平台或实例、版本、证据日期和状态（已订正、已替代、已撤销、待验证），与当前的环境、版本和命题范围对齐。不把单端实测、历史观测或背景摘要当成现行结论：现行规则以常驻提示词和技能为准，记忆条目只作背景。

## 诚实边界

只能报告「已从指定文件删除并回读确认」，不能声称已经清除了历史会话、备份、Git 历史、压缩摘要或当前上下文里的副本。
