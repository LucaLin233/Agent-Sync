# Minis 记忆：条目校验与日志注入

先取得本包入口必需规则；其中工具与命令仅在 Minis 端可用。

## 条目格式与压缩门禁
- **条目格式体检**：`/var/minis/shared/memory-tools/verify-memory-format.py`（只读；按**条目**判定条目数、关键词行、时间戳、词数与字节预算；退出码 1＝有硬失败）。写入或整理记忆后跑一次，用于发现漏项；`--strict-terms` 是**回补专用**严格档（要求词在正文原样出现，比规则严，勿用于判断既有条目）。它是事后查漏工具，**不是写入强制入口**，不得据此宣称格式已强制。
- **条目压缩门禁**：`/var/minis/shared/memory-tools/entry-guard.py`（只读）——压缩某条记忆前后，用 `--old <压缩前副本> --new <当前文件>` 逐条比对**可检索标识是否丢失**（哈希/提交号/job id/`skl_*`/路径/文件名/容量/常量名），并检查条目数与关键词行。硬失败非 0 即不得宣称压缩无损。**子代理自述不代替父级核对**——父级可核对象哈希、命令、退出码与原始结果，证据不足或对象变化才重跑。

## 日志自动注入与容量
- **Minis 日志自动注入**：2026-09-19 本机实测（App 版本未记录）：记忆开启时按文件日期取当天与前两日，每份截前 199 物理行而非按 mtime、字符或 token 截取；注入字符量约为各文件所取行数 × 其平均字符数之和，token 数另取决于文本与 tokenizer。仅适用于该本机观察仍成立的 Minis：第 200 行起不自动注入，跨界条目可能不完整，线后条目不注入。以每日实际日志 **≤199 物理行为完整注入目标**，暂以**每日约 25,000 B 作为文本规模观察目标**，二者分别核算，不是写入工具硬限或跨端规则（计数含标题、时间戳及空行）。接近/超标时检查重复、完整条目与截断边界；不为达标删事实、补空行、机械折行、拆散条件或擅自整理历史。无法兼顾时保留必要事实，报告超标及可能截断，不宣称完整注入。单条 2 KiB 编辑软预算依 `luno-memory/SKILL.md`。授权内折短长行可减量，却可能将原文推到截断线外，不保证关键结论及条件完整；折行宽度依当次目标与边界确定，非 App 上限或日常硬规则，不自动批量重排历史。去空白相等仅证去空白后的字符序列一致，不代语义、Markdown、代码空白或截断边界核对。App 更新/开关或观察改变须重核，并在记忆开启的新会话验证注入，不以当前会话/文件回读代替。
