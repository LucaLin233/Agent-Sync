## 执行环境分流（Minis 端）

先取得本包入口必需规则。
本端有两个 Linux 执行面：本机 **iSH**（Alpine/aarch64，与 `/var/minis/*`、`apple-*`、`minis-*` 同侧）与远端 **OnlyBoxes 沙箱**（远程调用）。下列为**选址判据**，按序过滤，前项不过即停；**本节只提供选址依据，不授予任何端使用该沙箱的权限**，跨端同步不等于其他端获得授权。

引用 OnlyBoxes 的版本、镜像能力或测量成本作选址建议／结论前，须完整读取 `references/onlyboxes-baseline.md`；资源不可得、版本未核或证据只有历史样本时，暂停依赖该证据的判断，不把历史能力、限额或成本当作现值。有限测量不得外推。

1. **准入与禁止（硬约束）**：沙箱只承接**准入通过**的任务——来源与版本可追溯，入口与依赖的执行行为已核对，无未审的动态下载与执行；**助手或模型生成的代码同样按此核对，核对不了即不准入**。不承接不可信代码与来源不明的脚本／二进制（**非安全隔离区**）。不承载秘密、生产凭据与生产数据；**默认不访问宿主与私网服务**，公网仅限任务必要目标，禁扫描、洪泛与代理转发；本机侧评估仅指只读静态检查，运行不可信代码须先有独立隔离环境。
2. **环境资格与默认归属**：区分执行时必须直接访问本机能力与最终交付位置；下列默认沙箱类通过第 1、3、4 步就派沙箱，不因本机也能做或更熟改判。结果最终存本机不排除授权内沙箱计算后回传；硬约束淘汰候选环境，不淘汰任务。
   - **默认沙箱**：纯计算、统计／数据处理、媒体转码、文档转换、x86_64 wheel 与需 glibc 行为的任务、gcc／g++／make 编译和小构建、批量文本／正则／日志解析及 JSON／CSV／SQLite／zip 转换。具体镜像能力须按基线当前证据核对。
   - **混合（本机取数／编排／落盘＋远端计算）**：本机源文件批处理、可断点长任务（分段派发、逐段回传）、公共 HTTP 抓取与解析。
   - **保持本机（不得默认外派）**：需读写 `/var/minis/*` 或需 `apple-*`／`minis-*`／记忆／已有浏览器会话的子任务；规则仓库测试；秘密、生产凭据／数据、不可信代码、宿主与私网探测；目标服务器真实状态与服务操作（走既有 SSH 授权通道）。规则仓库测试不把 `TMPDIR` 指向 Minis 共享目录。
   - **不迁移**：毫秒级小操作；超过已核上界或资源上界不明的任务；无法给出完整回传校验的大产物；要求 Alpine／musl、aarch64 或与生产目标完全同构的验收。

   `computerUse` 与 `CU:<worker_id>` 路径按禁用处理；工具列出不等于可调用，也不据此断言服务端不可用。
3. **资源资格**：任务须能给出运行时长与磁盘／日志／解压／缓存／并发的上界，并逐项不超过 `onlyboxes-baseline.md` 当前证据支持的 vCPU、内存、pids、磁盘和回传界限；给不出上界、基线未核当前界限或会并发压满宿主，即不派沙箱。资源上界随版本或镜像变化须整体重核。
4. **交付与结果完整性**：结果必须完整回传并通过目标校验（按工具使用长度、序号、总长、哈希、解码或其他适用校验）；截断、缺块、目标不完整或校验失败均不算交付。工具／协议报错、执行状态不明或 lease 到期时按结果未知处理；不得盲重试、跨协议重跑或静默改由 iSH 承接重计算。
5. **成本择优**：仅在前四步通过后比较成本；基线中的耗时、固定开销与能力数字均按日期和版本解释，历史样本不得外推为跨时段常量。耗时未知标未知，不为定路由先跑一遍完整任务；只有批量化等有依据的复用才可纳入比较。
6. **未知或失败**：不擅自换环境；OnlyBoxes 不可用、工具能力未核或结果未知时，报告证据、停止依赖该结果，并按能力降级或暂停，不静默改由 iSH 承接。
