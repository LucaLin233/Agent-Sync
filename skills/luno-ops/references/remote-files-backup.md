先取得本包入口必需规则。

## 工作目录（远端）
- **Minis 端上机全部主机通用**：过程产物——脚本草稿与被测副本、夹具、日志、克隆副本、样本、临时快照——统一落在 `/root/workdir/minis/<项目>/`；根目录不存在则 `install -d -m 700 /root/workdir/minis`。**项目目录按任务对象命名、同一对象始终复用，不在 `/root` 顶层散落文件。** 目录 700、文件 600；保留结论性产物；临时文件收尾按 `luno-core/SKILL.md`〈执行闭环〉。
- **例外（按其正式路径落位，不进工作目录）**：交付件与生产文件本身落到它服务的正式路径（如 `/root/<脚本>.sh`、`/usr/local/bin/`、`/etc/**`）；备份根 `/root/backup/` 按〈备份〉节，设备与实例既有路径（`/root/env/`、`/root/connect-device.sh`、`/root/lobehub/` 等）不动。**开发中草稿在工作目录，交付/装机版本落正式路径。**
- 历史遗留不追溯、不清理；用户明确要求整理时才合并，原路径保留至其确认删除。
- **LobeHub 端**：**执行目录**由平台侧工作目录设置决定，不套用 Minis 路径；同一主机上由 Minis 端整理或产出的 LobeHub 过程产物归 `/root/workdir/lobehub/`（不在 `/root` 顶层散落），LobeHub 端自身既有工作目录不动。

## 备份（远端通用）
- 远端备份统一落在 `/root/backup/`，**顶层只允许这一个目录**（不得再出现 `/root/backups`、`/root/luno-backups` 这类平行备份根）；不存在则 `install -d -m 700 /root/backup`，目录 700、文件 600。
- 目录按**对象或用途**划分（如 `db/`、`config/`、`platform/`；一次性批次用 `<批次名>-<日期>/`），**层级不超过两层**；优先复用已有目录，不为单次任务新开。
- 历史遗留备份默认不迁移、不清理；用户明确要求整理时才合并，原目录保留至其确认删除。
- 命名 `<对象>.<用途>.<YYYYMMDD-HHMM>`（如 `db/lobehub.dump.20260915-0930`）；临时快照（改配置前的就地 `.bak`）同样放此处，任务结束前删除，不留配置文件同目录。
- **有限滚动备份**（按目录/对象）：备份前比对目标与最新备份，一致不重复；同一对象保留最近 **1 份**，数据库与整机 dump 保留 **2 份**。淘汰前须校验新份非空、大小合理，并按类型在目标主机只读校验恢复完整性：dump 须工具成功结束、格式可列举、全部数据可解码且与完成时可信校验和一致（PostgreSQL custom/directory/tar 可用 `pg_restore --list` 后不带 `--dbname` 将完整恢复脚本输出至空设备）；归档须列表可解析、压缩/成员校验通过（如 `gzip -t`／`unzip -t`），并核完成时可信校验和；普通副本仅由备份工具核源/备份校验和，不展示或解析凭据文件。列表或事后自算校验和不能单独证明可恢复；plain SQL／快照等缺充分只读判据时保留旧份，实际恢复演练交授权隔离环境。校验输出与错误原文不回传，只记路径、时间、大小、校验值与状态；未通过、未执行或证据不足均不得淘汰，保留并报告；只删 `/root/backup/` 下自己产生的备份。
- 容量上报：不设容量阈值，也不因容量大小另设暂停或确认关口；每次备份后以 `du -sb /root/backup` 统计目录总大小（表观字节数），并在当次交付中报告。
- **秘密与恢复**：诊断投影和完整恢复备份按 `luno-core/SKILL.md`〈授权与安全〉的〈秘密面〉；完整备份落本目录、文件 600，权限 600 不等于排除秘密。不得用脱敏导出冒称可恢复备份。
- 例外：流程要求备份必须在原目录才能生效的，须在对应技能里写明原因，不作默认例外。
