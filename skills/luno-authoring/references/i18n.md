# 软件国际化（i18n）

适用于代码、UI、locale、翻译键、复数、地区格式、RTL、回退和自动检查。优先复用项目现有的工具；只有验收确实需要、现有工具覆盖不了、并且有对应写入授权时，才新增最小的 i18n 检查脚本。报告实际检查的范围、跳过项和未覆盖的语言；工具通过不等于覆盖完整。

改动前先读项目的约定和 locale 文件，只改目标范围，保持键、变量、占位符和文件结构不变。检查要点：

- **硬编码**：已经调用 i18n 的文件也要查残留的硬编码文案，不整文件跳过。
- **键集**：按项目实际的组织方式（包括平铺的 `<locale>.json`，不假定形态），各语言的键对齐，没有缺键或多余键；同一个 locale 的文件里用户文案不混用语言（键、变量、占位符和专名除外）。
- **拼接与格式**：不拼接翻译串，占位符、复数和性数交给 ICU 或项目既有机制；日期和数字按目标 locale 格式化。
- **回退**：配置默认语言回退，并实测缺失翻译时的实际回退结果。
- **布局**：不假定译文长度；适用 RTL 时用逻辑属性，并实测布局和方向，不以用了逻辑属性代替实测。

改完运行可用的校验，报告修改的文件和键。
