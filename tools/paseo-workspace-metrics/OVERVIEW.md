# 工作区用量

输入 `/metrics` 或从命令中心打开当前工作区的用量面板；已有对话的输入框工具条显示「缓存 98.2%」按钮（没有有效样本时显示「缓存 —」），点击打开该对话所属工作区的同一面板。面板显示最近的缓存命中样本、覆盖会话数和各会话的模型、状态、Token 用量。打开会话详情后，可观测后续完整轮次的首个助手消息事件和整轮耗时。内置 Claude Code 提供输出计数的成功轮次还显示整轮输出速率。输入框按钮与面板共用缓存率的汇总口径和一位小数格式；按钮随会话目录订阅更新，面板在打开或刷新时读取，两者采样时点可能不同。

适用 Paseo 0.17.1。`/metrics` 只在工作区输入框提供且不带参数。按钮跟随当前 host 的会话目录，已有对话会立即出现，归档或转入后台时移除，重连后按新目录重建。最近样本缓存率覆盖字段完整的 Codex 会话，包括可确认使用 Codex 的自定义 provider。累计缓存率、服务商首字延迟和纯生成速度在缺少对应数据时留空。插件通过 Paseo 读取当前工作区的会话元数据和用量，实时观测只使用事件元数据。
