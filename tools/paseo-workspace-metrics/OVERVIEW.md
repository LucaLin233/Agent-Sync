# 工作区用量

输入 `/metrics` 或从命令中心打开当前工作区的用量面板；已有对话的输入框工具条显示「缓存 98.2%」按钮。按钮优先显示当前 workspace 的 Codex 累计缓存率；加载中为「缓存 …」，累计接口不可用时为「累计 —」，无有效样本时为「缓存 —」。点击打开该对话所属工作区的同一面板。面板同时显示累计缓存率、累计覆盖、累计缓存读取/总输入，以及最近样本缓存率和最近覆盖，便于对照。打开会话详情后，可观测后续完整轮次的首个助手消息事件和整轮耗时。内置 Claude Code 提供输出计数的成功轮次还显示整轮输出速率。

适用 Paseo 0.17.1。`/metrics` 只在工作区输入框提供且不带参数。按钮跟随当前 host 的会话目录，已有对话会立即出现，归档或转入后台时移除，重连后按新目录重建。累计由 daemon 侧 RPC 读取 Codex rollouts：每个唯一 native 会话取最新一笔有效 `total_token_usage`，closed 计入，归档、后台、跨 workspace 和无法确认的会话排除，缺失不当零。host 设置的 `workspaceIds` 限定可查询的 workspace；数据根依次使用 `CODEX_HOME`、host 设置 `codexHome` 和 `~/.codex`；只进入固定的 `sessions/`、`archived_sessions/`，不跟随软链，不返回路径或正文。最近样本缓存率覆盖字段完整的 Codex 会话，包括可确认使用 Codex 的自定义 provider。服务商首字延迟和纯生成速度在缺少对应数据时留空。插件通过 Paseo 读取当前工作区的会话元数据和用量，实时观测只使用事件元数据。
